-----------MISSION-----------
Build a reusable Docker image for a real Node.js API, configure it safely at runtime, demonstrate effective
layer caching, and explain Dockerfile behavior like a production DevOps engineer.

----------------------

-----------Learning outcomes-----------
• Write an application Dockerfile using FROM, WORKDIR, COPY, RUN, ARG, ENV, EXPOSE, USER and CMD.
• Explain COPY vs ADD, CMD vs ENTRYPOINT, and ARG vs ENV with a working test.
• Use .dockerignore to keep the build context clean and avoid accidental secret inclusion.
• Inspect image metadata and build output; demonstrate a dependency-layer cache hit.
• Provide a reproducible GitHub submission with screenshots and a short README.
----------------------
